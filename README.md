# MKK-SGT

MKK Scenario Game Tools (`mkk_sgt`) - набор инструментов для подготовки сценариев Arma 3.

## Возможности

- дневниковое меню сценарных действий;
- служебные маркеры групп, техники, ящиков, строений и ботов;
- сохранение и загрузка пользовательских маркеров в слоты профиля;
- отметки высоты и тайминг перемещения;
- краткие отчеты по группам, технике и условностям;
- вселение в юнита под курсором.
